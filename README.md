# Web Development Project: Departmental Voting System

A web-based voting application that allows students to vote for their preferred candidates during departmental executive elections. 
The system supports elections for positions such as President, Vice President, and Secretary, while providing administrators with tools to manage departments, candidates, and election results.


## Features

- Authentication and Authorization: Student registration and login, routes guards, Role-based access to student and admin.
- Candidate Management (Add, remove and disqualify candidates)
- Department Management
- Administrator Management
- Voting System
- Election Results

## Technologies Used

PHP, HTML, CSS, JS, 

## Key Areas of Implementation include:

- Database design
- Form handling and Input Validation
- Data retrieval





The Departmental Voting System provides a centralized platform for managing departmental elections and simplifies the process of voting for student executives. It combines student-facing voting functionality with administrative tools for managing departments, candidates, and election results.

The project also provides a foundation for future improvements, including scheduled elections, candidate applications, notifications, and historical election management.
